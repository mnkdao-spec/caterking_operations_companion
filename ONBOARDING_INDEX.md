## Success Criteria

### Individual Onboarding Success

You're successfully onboarded when you can:

1. ✅ Run all applications locally without errors
2. ✅ Explain project architecture
3. ✅ Navigate codebase independently
4. ✅ Create feature branch and implement code
5. ✅ Write tests for your code
6. ✅ Create and submit PR
7. ✅ Address code review feedback
8. ✅ Merge PR to main
9. ✅ Ask for help appropriately
10. ✅ Pick and complete next task independently

### Team Success

The team is functioning well when:

1. ✅ All onboarded members productive
2. ✅ Tasks completed on schedule
3. ✅ Code quality high
4. ✅ Communication clear
5. ✅ Minimal blockers
6. ✅ Knowledge shared
7. ✅ Team morale positive

## Common Questions

**Q: How long does onboarding take?**  
A: 1-3 days depending on role. See role-specific checklists.

**Q: What if I get stuck?**  
A: Post in #caterking-dev, comment on Linear, or schedule pair programming.

**Q: Where are the database credentials?**  
A: In `.env.local` files (provided by team lead).

**Q: How do I run tests?**  
A: Run `pnpm test` in root or specific directory.

**Q: What's the first task I should do?**  
A: See your role-specific section above.

**Q: Who do I ask for help?**  
A: Post in #caterking-dev or comment on Linear issue.

**Q: How do I know if my code is working?**  
A: Test locally, run tests, verify no TypeScript errors.

**Q: Can I work on multiple tasks?**  
A: Start with one, complete it, then pick next task.

## Useful Commands

```bash
# Install dependencies
pnpm install

# Start development servers
pnpm dev

# Run tests
pnpm test

# Type check
pnpm check

# Format code
pnpm format

# Lint code
pnpm lint

# Build for production
pnpm build

# Create feature branch
git checkout -b feature/OLD-XX-description

# View recent commits
git log --oneline -10

# Check git status
git status
```
